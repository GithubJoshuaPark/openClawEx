## 1. 결론: 둘 다 실행할 필요 없음 (하나만 실행)

**`runclaw`와 `claw`를 차례대로 둘 다 실행하실 필요는 전혀 없습니다.**
두 명령어는 동일한 macOS 백그라운드 서비스(`ai.openclaw.gateway`)를 구동하는 서로 다른 방법(저수준 launchctl vs OpenClaw CLI)입니다.

- `claw`: `openclaw gateway start`를 실행하여 OpenClaw CLI가 상태를 점검하며 서비스를 시작시킵니다. (**가장 추천**)
- `runclaw`: `launchctl load ... && launchctl start ...`를 직접 호출합니다. (단, 이미 load되어 있는 상태라면 중복 load 경고가 발생할 수 있습니다.)

따라서 외출 전에는 **`claw` 하나만 실행**하시면 충분합니다.

---

## 2. 외출 전 권장 실행 순서 (3단계)

### 1단계: 게이트웨이 시작
터미널에서 `claw` 입력:
```bash
claw
```

### 2단계: 정상 구동 및 온라인 확인
```bash
listclaw
# 또는
openclaw gateway status
```
- PID 숫자가 정상적으로 표시되고 `running` 상태인지 확인합니다.
- 스마트폰 Discord 앱을 열어 봇 프로필이 **🟢 온라인**으로 바뀌었는지 확인하고 멘션 테스트(예: `@봇 안녕`)를 보냅니다.

### 3단계: 종료 시 (귀가 후)
외출에서 돌아와 봇을 끄고 싶으실 때는:
```bash
killclaw
# 또는 openclaw gateway stop
```

## 3. 🚨 매우 중요한 외출 시 맥북 주의사항 (잠자기 방지)

맥북(MacBook Pro Intel)을 켜두고 외출하더라도, **일정 시간이 지나 맥북이 잠자기(Sleep Mode)에 들어가면 네트워크(Wi-Fi)가 끊겨 Discord 봇이 오프라인**으로 바뀝니다.

### 외출 시 필수 체크:
1. **전원 케이블(충전기) 연결**: 배터리 모드에서는 화면이 꺼지면 바로 절전 모드로 진입합니다.
2. **잠자기 방지(Caffeinate) 실행**:
   - 맥북 화면을 열어둔 상태로 두시거나, 잠자기를 원천 방지하려면 터미널에서 다음 명령어를 실행해 두세요:
   ```bash
   caffeinate -dimsu &
   ```
   *(귀가 후 `killall caffeinate`로 해제)*
   - 또는 Amphetamine / Caffeine 같은 잠자기 방지 앱을 사용 중이시라면 활성화해 두셔야 합니다.
