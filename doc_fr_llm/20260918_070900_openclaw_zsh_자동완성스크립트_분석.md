## 1. 파일의 본질 및 역할

이 파일은 Zsh 셸 환경에서 `openclaw` 명령어를 입력하고 `Tab` 키를 눌렀을 때, **사용 가능한 모든 명령어, 하위 서브 커맨드, 세부 옵션/플래그 및 설명 텍스트를 자동으로 완성(Auto-completion)해 주는 Zsh Completion 스크립트**입니다.

- 파일 최상단: `#compdef openclaw` (Zsh 자동완성 시스템 등록 지시문)
- `_arguments -C` 함수 체인을 통해 계층적 파싱 및 서브 커맨드 인자 분기 처리 (`_openclaw_root_completion` -> `_openclaw_<명령어>`)

## 2. 전역 플래그 (Global Options)

루트 레벨에서 모든 서브 커맨드에 공통 적용할 수 있는 옵션들입니다:

| 전역 옵션 | 축약형 | 설명 |
| :--- | :--- | :--- |
| `--version` | `-V` | OpenClaw 버전 정보 출력 |
| `--container` | - | Podman 또는 Docker 컨테이너 내부에서 CLI 실행 |
| `--dev` | - | 개발 전용 격리 프로필 활성화 (`~/.openclaw-dev`, 게이트웨이 포트 19001) |
| `--profile <name>` | - | 사용자 지정 프로필 격리 모드 (`~/.openclaw-<name>`) |
| `--log-level` | - | 파일 및 콘솔 출력 로그 레벨 오버라이드 (`silent|fatal|error|warn|info|debug|trace`) |
| `--no-color` | - | 터미널 ANSI 색상 출력 비활성화 |

### ① 초기화 및 설정 (Setup & Config)

| 서브 커맨드 | 주요 설명 |
| :--- | :--- |
| `setup` | 활성 OpenClaw 설정 및 에이전트 기본 워크스페이스 디렉토리 초기화 |
| `onboard` | 게이트웨이, 워크스페이스, 모델 제공자, 인증 키, 스킬을 설정하는 대화형 온보딩 마법사 |
| `configure` | 자격 증명, 채팅 채널, 게이트웨이 및 에이전트 기본값 대화형 변경 |
| `config` | `openclaw.json` 설정값 비대화형 관리 도구 (`get`, `set`, `unset`, `file`, `schema`, `validate`) |
| `backup` | OpenClaw 상태(설정, 인증 정보, 세션, 워크스페이스)의 로컬 백업 아카이브 생성 및 검증 (`create`, `verify`) |

| `uninstall` | 게이트웨이 서비스 등록 해제 및 로컬 데이터 삭제 |
