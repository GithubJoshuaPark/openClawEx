## 1. 프로젝트 개요

`openClawEx`는 로컬 macOS 환경에서 자율형 AI 에이전트 플랫폼인 **OpenClaw**를 설치, 운영, 관리하기 위한 **종합 가이드 및 모니터링 대시보드(Mission Control Dashboard)** 프로젝트입니다.

- **핵심 목표**:
  1. 맥북(로컬)에서 백그라운드로 구동되는 OpenClaw 에이전트를 Discord와 연동하여 외부(iPhone 등 모바일)에서 로컬 프로젝트들을 원격 제어 및 관리.
  2. Gemini 2.5 Flash(Primary)와 Claude Sonnet 4.6(Fallback)으로 구성된 **이중 방어막(Dual Shield)** 고가용성 AI 파이프라인 구축.
  3. 설치, 운영, 트러블슈팅 절차를 체계적으로 문서화하고, 이를 웹 대시보드(Firebase Hosting) 형태로 시각화하여 제공.

## 3. 핵심 아키텍처 및 동작 메커니즘

### 3.1. 에이전트 실행 모드
1. **Gateway 모드 (`openclaw gateway start`)**:
   - macOS `LaunchAgent` 데몬으로 백그라운드 상시 구동.
   - Discord Bot(WebSocket)과 실시간 연동되어 모바일 푸시 알림 및 외부 메시지 수신/응답 수행.
2. **Terminal 모드 (`openclaw` / `openclaw tui`)**:
   - 터미널 기반의 1:1 대화형 세션으로 로컬 파일 시스템 직접 접근 및 즉각적인 코드/Git 작업 수행.

### 3.2. 이중 방어막 (Dual Shield) 모델 Failover
- **Primary**: `google/gemini-2.5-flash`
- **Fallback 1**: `anthropic/claude-sonnet-4-6`
- Rate Limit 또는 특정 모델 장애 발생 시 서비스 중단 없이 즉시 하위 모델로 자동 전환.

### 3.3. 원격 프로젝트 관리 및 프로토콜
- 외부에서 Discord를 통해 로컬 프로젝트(`fieldMates`, `seoultrip`, `soromiso.kr`)의 코드 수정, 빌드 테스트 지시.
- **Build-Before-Commit 프로토콜**: 에이전트가 코드를 수정한 후 반드시 `npm run build` 검증을 통과한 경우에만 Git 커밋/푸시를 진행하도록 통제.

### 3.4. Mission Control 웹 대시보드
- Firebase Hosting 타깃(`openclawex`)을 통해 `https://openclawex.web.app/`에 배포.
- 가이드 문서 열람, 게이트웨이 상태 가이드, 트러블슈팅 내용을 웹 UI로 손쉽게 확인 가능.
