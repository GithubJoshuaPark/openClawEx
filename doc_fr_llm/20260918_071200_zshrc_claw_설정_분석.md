## 1. 조회 결과 전체

```bash
alias claw='source ~/.nvm/nvm.sh && nvm use 24.7.0 && openclaw gateway start'   # Discord 봇
alias clawchat='source ~/.nvm/nvm.sh && nvm use 24.7.0 && openclaw tui'         # 터미널 채팅
alias killclaw="launchctl unload ~/Library/LaunchAgents/ai.openclaw.gateway.plist"
alias listclaw="launchctl list | grep openclaw"
alias runclaw="launchctl load ~/Library/LaunchAgents/ai.openclaw.gateway.plist && launchctl start ai.openclaw.gateway"
source "/Users/soromiso/.openclaw/completions/openclaw.zsh"
```

## 2. 항목별 세부 분석 표

| 항목 (Alias / Source) | 실제 실행 명령어 | 역할 및 목적 | 사용 시점 및 특징 |
| :--- | :--- | :--- | :--- |
| **`claw`** | `source ~/.nvm/nvm.sh && nvm use 24.7.0 && openclaw gateway start` | **Discord 연동 백그라운드 게이트웨이 시작** | 맥북 재부팅 후 또는 봇 시작 시 사용. Node v24.7.0 환경을 보장하며 Gateway를 구동함. |
| **`clawchat`** | `source ~/.nvm/nvm.sh && nvm use 24.7.0 && openclaw tui` | **터미널 대화형 인터페이스(TUI) 실행** | 터미널 화면에서 에이전트와 직접 1:1 대화 및 작업을 수행할 때 사용. |
| **`killclaw`** | `launchctl unload ~/Library/LaunchAgents/ai.openclaw.gateway.plist` | **LaunchAgent 데몬 완전 언로드(중지)** | 백그라운드에서 실행 중이거나 상주하는 OpenClaw 서비스 데몬을 완전히 내리고 비활성화할 때 사용. |

| **`runclaw`** | `launchctl load ~/Library/LaunchAgents/ai.openclaw.gateway.plist && launchctl start ai.openclaw.gateway` | **LaunchAgent 데몬 수동 로드 및 즉시 시작** | `plist` 파일을 `launchctl`에 다시 등록(load)하고 강제로 서비스를 시작(start)할 때 사용. |
| **`source ...`** | `source "/Users/soromiso/.openclaw/completions/openclaw.zsh"` | **Zsh 자동완성 활성화** | 셸 시작 시 OpenClaw 명령어 탭 자동완성(Tab-completion) 기능을 로드함. |
